# Simulador-mips
Projeto voltado a ler as instruções MIPS em hexadecimal, identificar/decodificar cada uma e gerar um JSON de saída para cada instrução correspondente

## Atualmente o programa realiza:
Hexadecimal
→ Binário
→ Identificação do formato
→ Decodificação dos campos
→ Identificação da instrução
→ Geração do texto da instrução
→ JSON de saída
